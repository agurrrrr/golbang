## 4.0 prefix cache API 스파이크 결과

- 사용 심볼: `llama_memory_seq_cp` / `llama_memory_seq_rm` / `llama_memory_seq_keep`
- 결과: **가능** — `golbang-sys/bindings.rs`에서 해당 심볼 바인딩 확인됨
  (`llama_kv_cache_seq_*`가 아니라 `llama_memory_seq_*` SHA 기준).
- 축소안 적용 여부: **채택** — 전역 cross-slot prefix store는 도입하지 않고,
  슬롯 내 prefix KV 재사용(slot-local)만 사용. `PrefixStore`는 기본 비활성.
  - `slot.rs`: `prompt_offset`/`prefix_cache` 필드
  - `prefix_cache.rs`: `SlotPrefixCache::reuse()` → 공통 prefix 길이 반환
  - `batch.rs`: prefill을 suffix(`prompt_offset..`)부터 시작, `n_past=reuse_len`으로 시드
- 실제 벤치 측정: **GPU 환경 필요** (본 작업은 CPU 컴파일 검증 + 단위 테스트까지만 완료)
